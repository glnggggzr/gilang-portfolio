About · Stack

A small toolbox, used well.

I’m a web developer based in Indonesia, currently shipping four public repos in one month, and getting properly stuck into the part of the job that isn’t coding — naming things, planning migrations, deciding what not to build.

My stack is PHP — Laravel when the package ecosystem pays for itself, CodeIgniter 4 when I want every line of the request to be readable. I’m exploring AI-assisted workflows this year (yes, this page was scaffolded by one), with the goal of staying curious without losing the craft.
