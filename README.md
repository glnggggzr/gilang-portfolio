## What's here

A single-page portfolio with six sections: **hero**, **selected work**, **about**, **process** (how I work), **contact**, **footer**. Designed to be skim-able by recruiters and clients in under a minute, showcasing four apps built end to end (dashboard, roles, database, UI).

- ~115 KB HTML (~34 KB gzipped on the wire), plus self-hosted fonts and WebP screenshots
- **Self-hosted fonts** — Fraunces + IBM Plex Mono under `assets/fonts/`, no Google Fonts request
- `robots.txt` + `sitemap.xml` for search engines
- No tracking, no analytics, no third-party scripts

palette, motion rules, and the original prompt templates for the project mockups.
Keep it around so future-you doesn't have to re-derive the decisions.

## Quickstart

### Local preview

```bash
# Laragon (this repo lives in D:\laragon\www\gilang-portfolio) — already served.
# Or any static server:
python3 -m http.server 8000
npx serve .
```

## Deploy

The live site at <https://glnggggzr.github.io/gilang-portfolio/> is served from the **`gh-pages` branch** (Settings → Pages → branch `gh-pages`, folder `/`) — and that branch holds *only* `index.html` + `assets/**`. The source of truth is `main` (`references/`, `test/`, `capture-projects.js`, `cv.html` stay there and are never published).

So publishing takes **two pushes**. Pushing only `main` leaves the live site on the old version — this is the #1 gotcha in this repo.

```bash
REPO="D:/project/laragon/www/gilang-portfolio"   # adjust to your checkout
git -C "$REPO" push origin main                  # 1. source of truth

# 2. what visitors actually get (index.html + assets only)
git -C "$REPO" worktree add --detach "$REPO/../_ghpub" origin/gh-pages
cd "$REPO/../_ghpub"
rm -rf assets && cp -r "$REPO/assets" . \
  && cp "$REPO/index.html" "$REPO/favicon.svg" "$REPO/robots.txt" "$REPO/sitemap.xml" .
git add -A && git commit -m "deploy site (gh-pages)" && git push origin HEAD:gh-pages
cd - && git -C "$REPO" worktree remove --force "$REPO/../_ghpub"
```

Wait ~1–3 minutes, then confirm the new build is live (any file you added should answer 200):

```bash
curl -s -o current.html -w "%{http_code}\n" https://glnggggzr.github.io/gilang-portfolio/
```

Other hosts work too, since this is a plain static page: **Netlify** (drag-and-drop the folder), **Vercel** (`vercel` in the root, zero config), **Cloudflare Pages** (empty build command, output `.`).

## Tech

| Layer          | Choice                                                              |
| -------------- | ------------------------------------------------------------------- |
| Markup         | Semantic HTML5, single file                                         |
| Styling        | Hand-written CSS in a `<style>` block; CSS variables for the palette |
| Fonts          | Self-hosted: Fraunces + Plus Jakarta Sans + IBM Plex Mono (`assets/fonts/fonts.css`, no Google Fonts request) |
| Behaviour      | ~280 lines of vanilla JS: loader fade, nav-shadow, mobile nav, IntersectionObserver reveals, i18n switcher |
| Tests          | `npm install` then `npm test` — Playwright smoke test (`test/smoke.cjs`): overflow, images, a11y hooks, hamburger, i18n. Needs the site served |
| Build          | None. Open the file, edit, refresh.                                  |
| Dependencies   | Zero npm packages. Optional `package.json` for dev tooling only.     |

## Regenerating the project screenshots

`capture-projects.js` logs into each local app (Laragon `.test` domains) with Playwright and saves a 1440×900 viewport shot. Re-run it when an app's UI changes:

```bash
node capture-projects.js   # writes PNGs into assets/projects/
```

Then convert to the shipped format (WebP, 920px wide, q82) with PIL:

```python
from PIL import Image
im = Image.open('assets/projects/x.png').convert('RGB')
im.resize((920, round(im.height * 920 / im.width)), Image.LANCZOS) \
  .save('assets/projects/x.webp', 'WEBP', quality=82)
```

Keep the script's credentials in sync with the apps (the Dekalase/aplikasi-produk demo login is `admin@dekalase.test` / `admin123`).
