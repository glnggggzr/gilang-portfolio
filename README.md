## What's here

A single-page portfolio with five sections: **hero**, **selected work**, **about**, **contact**, **footer**. Designed to be skim-able by recruiters and clients in under a minute, with concrete links to four live GitHub repos.

- ~40 KB total payload
- Self-hosted fonts (Google Fonts) + a single inline `<style>` block
- No tracking, no analytics, no third-party scripts

## Project layout

```
gilang-portfolio/
├── index.html                 # the whole site (HTML + CSS + ~280 lines of JS)
├── assets/
│   ├── projects/              # real app screenshots (WebP, 920px — regenerated by capture-projects.js)
│   └── og-image.jpg           # 1200×630 share card
├── capture-projects.js        # Playwright: logs into the local apps and screenshots them
├── references/                # design notes, brand spec, generation prompts (see below)
├── DESIGN.md                  # visual identity + voice + layout rules
├── LICENSE                    # MIT
└── README.md
```

The `references/` folder is a **design notebook** — voice + tone guidelines, brand
palette, motion rules, and the original prompt templates for the project mockups.
Keep it around so future-you doesn't have to re-derive the decisions.

> **Note:** an earlier version of this repo scaffolded a scroll-scrubbed 3D
> experience on top of [`oso95/scroll-world`](https://github.com/oso95/scroll-world).
> That work was archived into `references/` for posterity; the current site is a
> plain one-page portfolio. See `DESIGN.md` § 9 for the file-layout rationale.

## Quickstart

### Local preview

```bash
# Laragon (this repo lives in D:\laragon\www\gilang-portfolio) — already served.
# Or any static server:
python3 -m http.server 8000
npx serve .
# Or just drag-and-drop index.html into a browser.
```

### Edit the site

Open `index.html` in any editor. The whole page is in one file:

- **Copy / content** — search for the section, edit the text in place.
- **Visual rules** — read `DESIGN.md` first. Every choice has a reason.
- **Adding a project** — see `DESIGN.md` § 7.

## Deploy

This is a static page. Pick any one:

- **GitHub Pages** — Settings → Pages → branch `main` / folder `/`.
- **Netlify** — drag-and-drop the folder at https://app.netlify.com/drop.
- **Vercel** — `vercel` in the project root, zero config.
- **Cloudflare Pages** — connect the repo, build command empty, output `.`.

## Tech

| Layer          | Choice                                                              |
| -------------- | ------------------------------------------------------------------- |
| Markup         | Semantic HTML5, single file                                         |
| Styling        | Hand-written CSS in a `<style>` block; CSS variables for the palette |
| Fonts          | [Fraunces](https://fonts.google.com/specimen/Fraunces), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) (Google Fonts) |
| Behaviour      | ~280 lines of vanilla JS: loader fade, nav-shadow, mobile nav, IntersectionObserver reveals, i18n switcher |
| Tests          | `npm test` — Playwright smoke test (`test/smoke.cjs`): overflow, images, a11y hooks, hamburger, i18n. Needs the site served (Laragon) |
| Build          | None. Open the file, edit, refresh.                                  |
| Dependencies   | Zero npm packages. Optional `package.json` for dev tooling only.     |

## Regenerating the project screenshots

`capture-projects.js` logs into each local app (Laragon `.test` domains) with Playwright and saves a 1440×900 viewport shot. Re-run it when an app's UI changes:

```bash
node capture-projects.js   # writes PNGs into assets/projects/
```

Then convert to the shipped format (WebP, 920px wide, q82) with PIL:

```python
from PIL import Image
im = Image.open('assets/projects/x.png').convert('RGB')
im.resize((920, round(im.height * 920 / im.width)), Image.LANCZOS) \
  .save('assets/projects/x.webp', 'WEBP', quality=82)
```

Keep the script's credentials in sync with the apps (the Dekalase/aplikasi-produk demo login is `admin@dekalase.test` / `admin123`).
