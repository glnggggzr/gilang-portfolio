# Gilang — Scroll-Portfolio

> Personal portfolio of Gilang — a web developer building with Laravel & CodeIgniter.
> Rendered as a **scroll-scrubbed 3D world**: as you scroll, the camera flies between
> five diorama scenes (Hero → About → KlinikApp → KlikKode → Contact).

Built on top of [`oso95/scroll-world`](https://github.com/oso95/scroll-world) — a portable,
framework-agnostic scrub engine + an asset-generation pipeline (Higgsfield / Codex).
This repo is the project-specific scaffold: scenes, copy, prompts, and a deployment
runbook.

## Quickstart

### Local preview

```bash
# Any static server works. PHP has one built-in via Laragon, or:
python3 -m http.server 8000          # if you have python
# or just drag-drop index.html into a browser
```

### Generate the real 3D assets

See [`references/runbook.md`](references/runbook.md). TL;DR:

1. Install Higgsfield CLI / Codex CLI.
2. Generate 5 stills + 5 dive clips + 4 connector clips.
3. Encode with ffmpeg per `references/pipeline.md`.
4. Swap the `.svg` placeholders → `.webp`, uncomment the `connectors[]` lines in `index.html`.
5. Push + deploy.

### Deploy

This is a static page. Pick any one:

- **GitHub Pages** — Settings → Pages → branch `main` / folder `/` → Save.
- **Netlify** — drag-and-drop the folder at https://app.netlify.com/drop.
- **Vercel** — `vercel` in the project root, zero config.
